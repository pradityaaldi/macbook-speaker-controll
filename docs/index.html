Mono downmix

Switching a speaker off normally drops whatever was in that channel. Mono sums left and right inside the audio driver, so nothing goes missing.

kAudioHardwarePropertyMixStereoToMono

Pan law

Balance on these devices is not a mixer. The sliders invert its measured constant-power curve, so 100% / 50% is a real 2:1 ratio.

p = 2/π · atan2(right, left)

Install

One command, no build tools.

Downloads the latest release into /Applications, clears the download flag so Gatekeeper stays quiet, and launches it in your menu bar. No second command, no warning dialog.

Terminal 
curl -fsSL https://raw.githubusercontent.com/pradityaaldi/macbook-speaker-controll/main/install.sh | bash

By hand

Or take the zip.

  1. Download the bundle from the latest release.
  2. Move Speaker Control.app to /Applications.
  3. Clear the download flag, then launch it:
xattr -dr com.apple.quarantine "/Applications/Speaker Control.app"

A browser download carries a quarantine flag, and the bundle is ad-hoc signed rather than notarized, so macOS asks about it. The curl line above never sets that flag.
